# Bookmark Studio — 学习指南

欢迎！如果你是初次接触 Visual Studio 扩展开发，这份文档将帮你快速理解这个项目的代码框架。

## 阅读顺序

| 文档 | 内容 | 适合 |
|------|------|------|
| [01-项目概览](01-Project-Overview.md) | 这个扩展是什么、能做什么、技术栈一览 | 所有人，先读这个 |
| [02-代码框架](02-Code-Framework.md) | 项目结构、分层架构、每个文件的作用 | 了解代码怎么组织的 |

## 适合什么人

- 了解 C# 基础语法，想学习 VS 扩展开发的开发者
- 拉取了代码但不知道从哪里开始看的 Contributor
- 想参考这个项目结构来创建自己的 VS 扩展的人
